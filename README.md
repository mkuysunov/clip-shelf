# ClipShelf

Лёгкий менеджер истории буфера обмена в стиле [Paste](https://pasteapp.io): текст, ссылки и изображения.
Electron + React + Vite + TypeScript. Интерфейс на русском и английском.

## Запуск

```bash
npm install
npm run dev        # разработка (Vite + Electron с hot reload интерфейса)
npm run typecheck  # проверка типов (заодно компилирует electron/ в dist-electron/)
npm start          # проверить типы, собрать и запустить
npm run dist       # собрать .dmg в папку release/
```

Main и preload Electron не умеет запускать из `.ts`, поэтому `tsc` компилирует `electron/` в `dist-electron/`
(`npm run dev` делает это один раз при старте — после правок в `electron/` dev нужно перезапустить).

`npm run dist` собирает **universal**-бандл (Intel x64 + Apple Silicon arm64 в одном `.dmg`), поэтому один и тот же
файл запускается на любом Mac. Минимальная версия системы — macOS 11 Big Sur (ограничение Electron 33).
Сборка только под arm64 на Intel-Mac не открывается: «…не поддерживается этим компьютером Mac».

Приложение живёт в строке меню (иконка планшета), без иконки в Dock.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `⌘⇧V` (настраивается) | Показать / скрыть панель |
| `←` `→` (панель сбоку — `↑` `↓`) | Выбор карточки |
| `⌥←` `⌥→` (панель сбоку — `⌥↑` `⌥↓`) | Передвинуть карточку (при ручном порядке / в коллекции) |
| `Enter` / двойной клик | Вставить в активное приложение |
| `⌘1`…`⌘9` | Быстро вставить N-ю карточку |
| `⌘C` | Только скопировать (без вставки) |
| `Delete` / `Backspace` | Удалить из истории |
| Любая буква / `⌘F` | Поиск |
| `⌘,` | Открыть окно настроек |
| `Esc` | Сбросить поиск / закрыть |

Карточки можно перетаскивать мышью в другие приложения (картинка уходит как PNG-файл).

## Первый запуск

При первом старте открывается окно приветствия: что делает приложение и какое сочетание открывает панель.
Показать его снова можно из окна настроек или из меню в строке меню.

## Окно настроек

Открывается кнопкой с шестерёнкой справа в панели, сочетанием `⌘,` или пунктом «Настройки…» в меню
в строке меню. Это отдельное окно поверх панели: панель при этом остаётся открытой, изменения применяются
сразу и видны в ней. Закрыть — `Esc` или `⌘W`, фокус вернётся в панель. Если при открытых настройках
переключиться в другое приложение, панель закроется как обычно, а окно настроек останется.

- **Расположение панели** — «Снизу» (по умолчанию), «Сверху», «Слева», «Справа». Снизу и сверху панель
  занимает всю ширину экрана, карточки идут лентой слева направо. Слева и справа — узкая колонка во всю
  высоту экрана: карточки идут сверху вниз, вкладки переносятся под поиск, выбор — `↑` `↓`.
  Выбирается плитками с мини-экраном, на котором видно, где окажется панель.
- **Режим** — «Обычный» / «Разработчик».
- **Порядок** — «Сначала новые», «Сначала старые», «Вручную». В ручном режиме карточки
  переставляются перетаскиванием или `⌥←` / `⌥→`, и повторное копирование не поднимает элемент наверх.
- **Язык** — RU / EN. По умолчанию берётся язык системы; если он не русский и не английский — английский.
  Язык влияет и на меню в строке меню.
- **Запускать при входе** — то же, что галочка в меню в строке меню.
- **Сочетание для открытия панели** — нажмите «Изменить» и наберите новое сочетание.
  Нужен хотя бы один из `⌘` `⌃` `⌥` плюс клавиша; один `⇧` не подходит. Если сочетание занято системой
  или другим приложением, покажется ошибка, а старое сочетание останется. Если при запуске сохранённое
  сочетание не удаётся зарегистрировать, приложение откатывается на `⌘⇧V`.

## Режим разработчика

Тёмная тема, моноширинный шрифт, а вместо фильтров по типу — вкладки:
**История буфера** и ваши коллекции сниппетов (Regex, JSON, Error Handling — что угодно).

- `+` на панели вкладок — новая коллекция (цвет назначается автоматически).
- На карточке истории появляется кнопка `+` — сохранить текст как сниппет в коллекцию.
  Заголовок берётся из первой строки, переименовать — иконкой карандаша.
- `×` рядом с активной вкладкой удаляет коллекцию (с подтверждением).
- Сниппеты вставляются так же, как элементы истории: `Enter`, двойной клик, `⌘1…⌘9`.
- Внутри коллекции карточки всегда можно переставлять перетаскиванием.

## Автовставка на macOS

Чтобы по `Enter` текст сразу вставлялся в предыдущее окно, приложению нужен доступ:
**Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** → включить ClipShelf
(в режиме `npm run dev` — включить **Electron** или ваш терминал).
Без этого разрешения элемент просто копируется в буфер, вставить можно вручную `⌘V`.

## Где хранятся данные

`~/Library/Application Support/clipshelf/`
- `history.json` — история (текст + превью картинок); порядок массива = ручной порядок
- `images/*.png` — оригиналы изображений
- `collections.json` — коллекции сниппетов
- `settings.json` — язык, режим, сортировка, расположение панели, сочетание клавиш, флаг пройденного приветствия

## Настройки

В начале `electron/main.ts`: сочетание по умолчанию, лимит элементов (300), интервал опроса буфера,
высота панели (снизу / сверху) и её ширина (слева / справа).

## Когда панель закрывается сама

При потере фокуса (клик мимо, `⌘Tab`; переход в окно настроек и обратно не считается), при свайпе на другой рабочий стол / полноэкранное приложение,
при блокировке экрана, уходе в сон и при изменении конфигурации дисплеев.

## Как это устроено

- **main** (`electron/main.ts`): каждые 500 мс опрашивает буфер (у Electron нет события «буфер изменился»),
  дедуплицирует по хэшу, хранит историю, регистрирует глобальный хоткей, показывает панель у выбранного
  края экрана под курсором, эмулирует `⌘V` через `osascript`.
- **preload** (`electron/preload.ts`): безопасный мост `window.clip` для интерфейса.
- **типы** (`electron/types.ts`): общий контракт main ↔ preload ↔ renderer — элементы истории, коллекции, настройки
  и интерфейс `ClipApi` моста `window.clip`. Только типы (`import type`): preload работает в sandbox и не может
  подключать локальные модули.
- **renderer** (`src/`): React-интерфейс — `App.tsx` (состояние, клавиатура, drag-and-drop),
  `Toolbar.tsx` (поиск, вкладки, кнопка настроек), `Settings.tsx` (окно настроек, открывается по `#settings`),
  `HotkeyField.tsx` (запись сочетания), `Onboarding.tsx` (окно приветствия, открывается по `#onboarding`), `Card.tsx` (карточка истории / сниппета), `i18n.ts` (словари ru/en).
- **иконка**: `build/icon.png` (1024×1024) — electron-builder сам делает из неё `.icns`.
